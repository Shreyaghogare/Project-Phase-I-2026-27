ABOUT THE PROJECT

Customer Churn Prediction

Predict whether a customer is likely to leave a service using customer and service-related information.

TECHNOLOGY

Built for a clear viva

  • Python and Flask for the web application
  • Pandas and NumPy for data preparation
  • Scikit-learn for machine learning
  • HTML, CSS and JavaScript for the interface

MACHINE LEARNING

How it works

The existing Random Forest Classifier receives the same encoded features used during training. Its prediction probability is translated into a low, medium, or high risk level for the customer profile.

Logistic Regression, Decision Tree, and a comparable Random Forest are evaluated on the Performance page.
